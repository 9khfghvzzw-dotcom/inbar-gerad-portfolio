# From Cow to Beef

A browser-based interactive simulation with a public application and source repository.

## Focus

Connecting simulation rules, persistent state, rendering, and player interactions in a working web experience.

## Work sample

The public repository includes JavaScript simulation and rendering modules, Python music-building utilities, and Python/SQLite ledger components. The project brings together software experimentation and a background in music.
